## 6. 被拒录音重试/删除 — 2026-10-27

已确认行为：**每轮总共三次被拒尝试，包含第一次**，之后在列表选择重试/删除。
默认重试，长按 OK 也重试；同一录音 ID 恢复待上传，重新开启三次预算。
上传成功或明确删除之前，处理槽始终占用，重试中、离线或重启后均不能录制新的一条。
不再生成 `.keep` 存档；已有 `.keep` 只作为未完成兼容输入。
已经存在的多条旧文件先保留并逐条处理完，不允许新增积压。

选择显示录音时间/时长并等待工作任务确认。重试/删除失败时保留文件和弹窗。
待上传重试优先于其它旧文件询问，第三次拒绝立即发布同一条录音的待处理状态。
关闭选择后恢复列表 tick，后续上传成功可刷新列表。
状态、重试策略、文件操作、布局及固定文字字形覆盖均有宿主检查。
