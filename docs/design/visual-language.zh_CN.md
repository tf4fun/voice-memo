# 语音日记 — 视觉设计语言

实现快照：2026-10-27。本文尺寸和视觉呈现以当前 UI 源码为准。
交互见[产品方案](../product/product-spec.zh_CN.md)，视觉待完善工作及验收在
[里程碑](../project/milestones.zh_CN.md)中跟踪。

## 1. 显示与通用控件

显示为 240×320 竖屏 RGB565。BSP 应用 30 px 屏幕圆角遮罩，外部填黑。
8 px 布局内缩本身不保证角落内容不被裁掉；下面坐标只是实现值，不代表已经实测验收布局。

`memo_ui_common` 创建平面矩形、标签和卡片。卡片由两个对象组成：偏移的墨色实心矩形，
以及带 2 px 边框的白色正面；显示/隐藏同时处理两者。没有模糊阴影或实时旋转/缩放效果，
不使用基线演示视觉外壳。

## 2. 设计变量

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `VM_PAPER` | `#F6F1E6` | 页面背景 |
| `VM_CARD` | `#FFFFFF` | 卡片填充 |
| `VM_INK` | `#141210` | 文字、边框、实心投影 |
| `VM_MUTED` | `#7A7368` | 次要文字 |
| `VM_SUN` | `#FFC53D` | 选中填充及待发圆环底色 |
| `VM_CORAL` | `#E5483F` | 录音标记、警告/错误、待发圆环 |
| `VM_RADIUS_CARD` | 12 px | 卡片圆角 |
| `VM_RADIUS_PANEL` | 14 px | 详情/设置面板 |
| `VM_STROKE` | 2 px | 卡片边框 |
| `VM_SHADOW` | 3 px | 投影偏移 |
| `VM_INSET` | 8 px | 布局内缩 |

240 px 屏宽下标准卡片正面宽 221 px（`240 - 2×8 - 3`）。
选中立即变黄并上移 2 px；列表行投影上移 1 px，设置选中只移动正面。

## 3. 字体

| 用途 | 当前来源 |
| --- | --- |
| 标签、列表摘要、设置、提示 | `memo_font_16`，Noto Sans SC Bold 子集，4 bpp |
| 转写正文 | `memo_font_20`，Noto Sans SC Regular 子集，4 bpp |
| 时间、时长、电量 | Montserrat 14 |
| 录音计时 | Montserrat 40 |
| 保存/取消选择 | Montserrat 20，英文标签 |

生成的未压缩源码位于 `assets/fonts/memo_font_16.c` 和 `memo_font_20.c`。
文件头记录生成来源/选项及字符集（GB2312 一级字、ASCII 和标点）。
可写描述符副本为标签/正文挂接 Montserrat 14/20 回退，包含 LVGL 符号。
详情文字会检查缺字并按码点记录日志。

## 4. 组件

列表卡片高 40 px、间距 46 px，左侧时间，摘要从卡片内 x=52 起，时长右对齐。
当前状态使用文字，不是此前方案的圆点系统。行标签没有完整的固定宽度省略布局。

录音电平表含十二根宽 12 px、间距 16 px 的矩形，初始高 20 px、y=190。
录音计时回调按 RMS 电平更新显示。

播放条为 48 px 胶囊，含符号、进度/总时长和短轨道；时长已知时，轨道宽度在 8–74 px 之间。

## 5. 页面尺寸

| 页面 | 当前布局 |
| --- | --- |
| 列表 | 顶部标题，分隔线 y=34；五行位于 y=44 + 46×序号；底部提示及电量标签 |
| 录音 | REC 标记，计时距顶 70；132×132 待发圆环距顶 46；十二根电平条和松手提示 |
| 录音确认 | 卡片 x=20、y=210、高 84，包含 save/cancel 文字 |
| 上传被拒 | 当前字体下列表浮层 x=18、y=42，201×236；20 px 选项横排，时间/时长/说明/提示 16 px，默认选重试 |
| 详情 | 顶部信息；正文从 y=44 起，展开高 190；底部提示上方有 48 px 播放胶囊 |
| 设置 | 七行高 36，位于 y=42 + 40×序号；底部提示；居中高 96 的调值浮层 |
| 配网 | 标题，分隔线 y=34；面板 y=48、高 176；状态/说明和底部提示 |

列表只有五个固定行对象，没有移动窗口。设置也按固定坐标排布，不滚动；第七行到 y=318，
与底部提示/圆角区域重叠。详情将正文面板设为可滚动，但应用没有执行按键滚动动作。
应用打开详情时使用展开尺寸。只有列表绘制电量。

被拒弹窗使用纯逻辑 `memo_rejection_layout`，按实际字体行高计算：16 px 子集行高 31 px，
20 px 子集行高 38 px。布局预留三行说明、横排选项和提示，不把字号当行高。

## 6. 动效与渲染

待发圆环在 1000 ms 内从 0 动画到 100，页面立即切换。
选中位移和详情尺寸直接赋值，没有此前提出的选中/面板动画。录音圆点是静态的；
录音计时和电平由 200 ms 输入循环心跳更新。

BSP 使用单 DMA 绘制缓冲，宽 × 20 行，即 240 px RGB565 下 9600 字节。
`CONFIG_LV_USE_CLIB_MALLOC` 让 LVGL 使用系统堆；保留的 24 KB 池配置在此模式下不分配
独立 LVGL 池。LVGL 任务外的界面调用使用 `bsp_lvgl_lock()`。
