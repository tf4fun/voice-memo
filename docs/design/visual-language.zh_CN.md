# 语音日记 — 视觉设计语言

状态：草稿，2026-10-26。适用于[设备端方案](../technical/client.zh_CN.md)描述的界面；
不改变任何产品行为。

## 1. 硬件给定的几何

| 事实 | 数值 | 出处 |
| --- | --- | --- |
| 面板 | ST7789P3，240 × 320 竖屏，RGB565 | `bsp_pins.h` |
| 可视形状 | 圆角矩形，**圆角半径 30 px** | `bsp_display.h` 的 `BSP_LVGL_SCREEN_RADIUS` |
| 圆角之外 | 纯黑，逐次 flush 打补丁 | `bsp_display_rounding.c` |
| 反色 | 面板需要 `INVON`，颜色按正常方式定义 | `BSP_LCD_INVERT_COLOR` |

这个遮罩是硬边界：画在距角 30 px 以内的任何内容都会被裁成黑色。于是有两条直接推论：

1. **安全区**：所有内容收进四周 8 px 的内边距，即 x 8–232、y 8–312。卡片永不贴边，
   也就不会被圆角弧线切掉一角。
2. **内部圆角必须小于屏幕圆角**：卡片用 12–14 px。若某张卡片的圆角等于 30，它读起来会像
   "第二块屏幕的边框"，而不是贴在屏幕上的一张卡片。

## 2. 设计语言

两个参照，刻意叠加：

- **贴纸风新粗野主义**：高饱和平涂、粗墨线描边、无模糊的硬投影、厚实的圆角块面、
  每个状态只用一个主色。
- **趣味化界面**：每样东西都像能撕下来贴到别处——卡片压着自己的投影，选中时整张卡被
  "抬起来"，录音红点会呼吸。

落到 240 × 320 这块屏上，具体就是：结构由描边承担而不是渐变，投影是三像素偏移的实心
黑块，所有可交互的东西都是一张能指着说的卡片。

## 3. 设计变量

### 颜色

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `INK` | `#141210` | 描边、主文字、硬投影 |
| `PAPER` | `#F6F1E6` | 页面底色 |
| `CARD` | `#FFFFFF` | 卡片填充 |
| `MUTED` | `#7A7368` | 次要文字、时间戳 |
| `SUN` | `#FFC53D` | 选中、待处理提示 |
| `CORAL` | `#E5483F` | 录音、失败 |
| `MINT` | `#2EC4B6` | 已完成、播放中 |

一共七项取值（六个色 + 底纸）。面板是 RGB565，所以取值必须拉开距离；上面几组是为了在
量化到 5-6-5 之后仍能区分而挑的。

### 形状与线宽

| 变量 | 数值 | 说明 |
| --- | --- | --- |
| `RADIUS_CARD` | 12 px | 列表行、设置行 |
| `RADIUS_PANEL` | 14 px | 大面板：正文、录音卡 |
| `RADIUS_PILL` | 高度 / 2 | 播放条、选项胶囊、状态点 |
| `STROKE` | 2 px | 所有卡片与分隔线；1 px 在这块屏上会"消失" |
| `SHADOW` | 3 px、无模糊、`INK` | 用一张偏移的圆角矩形画在卡片背后 |
| `PAD` | 10–12 px | 卡片内边距 |
| `GAP` | 6 px | 行间距 |

### 字体

| 角色 | 字体 | 字号 | 字重来源 |
| --- | --- | --- | --- |
| 列表行、设置标签、提示 | 中文子集 | 16 px | 用**粗体**字面生成 |
| 正文 | 中文子集 | 20 px | 用**常规/中等**字面生成 |
| 时间戳、时长、电量 | Montserrat | 14 px | 已启用 |
| 计时器、大数字 | Montserrat | 28 px | 需额外启用（约 20 KB） |

按字号分配字重，是让整体看起来像贴纸、又不把字体预算翻倍的关键：16 px 的文字短，需要
力气；20 px 的文字长，需要耐读。两个子集仍沿用设备端方案里的覆盖契约（GB2312 一级 +
标点 + ASCII）。

图标全部用 Montserrat 里的 LVGL 内建符号字形，因此不引入任何图标图片，也不占额外 RAM。

## 4. 组件

### 卡片

界面里唯一的容器。填充 + 2 px 墨线描边 + 12–14 px 圆角，再加一块向左上偏移 (3, 3) 的
实心墨块垫在背后。

```text
        ┌──────────────┐
        │    内容      │      ← 白填充、2 px 墨线、圆角 12
        └──────────────┘
           ██████████          ← 实心墨块，x/y 各 +3，同样圆角
```

实现方式是"背景对象 + 卡片对象"两个圆角矩形，**不是** LVGL 的 shadow：模糊投影每帧都要
重绘，是这颗芯片上最贵的特效。两个圆角矩形几乎不花钱。

### 选中态

选中不换成描边样式，而是把卡片**抬起来**：填充变成 `SUN`，投影从 3 px 增到 4 px，
卡片整体上移 2 px。一个主色、一个动作，隔着半米也能一眼看出来。

### 状态点

列表行末尾一个 8 px 的圆，四种状态，不用文字：

| 状态 | 画法 |
| --- | --- |
| 待上传 | 2 px `INK` 空心圆环 |
| 转写中 | 圆环中间一个 `MUTED` 实心点 |
| 失败 | `CORAL` 实心圆 |
| 完成 | 不画——没有符号就是成功 |

用形状而不是颜色来区分，色弱用户能读，5-6-5 量化之后也不会糊在一起。

### 行

高度 40 px，含 6 px 间距的节距 46 px。从左到右：时间（Montserrat 14，`MUTED`，44 px 宽）、
一行摘要（中文 16 粗体，`INK`，超长按字符边界截断加省略号）、时长（Montserrat 14，
`MUTED`，右对齐）、状态点。

### 电平条

十二根 8 × 16 px 的圆角短条，间隔 4 px；亮的根数由当前音频块的 RMS 决定。选离散短条而不是
连续电平表，因为它像贴纸，而且只花十二个矩形。

## 5. 页面布局

坐标都在 8 px 安全区内。高度预算：状态栏 32 px（y 8–40），内容区 y 40–288，提示栏 24 px
（y 288–312）。

### 列表

```text
┌──────────────────────────────┐
│ 备忘                   82%   │  状态栏，下方 2 px 分隔线
├──────────────────────────────┤
│ 今天                          │  日期分组头，中文 16 粗体
│ ┌──────────────────────────┐ │
│ │ 08:32 和张工对了下测试…   │ │  行，高 40
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 07:15 买牛奶 鸡蛋 面包 0:12│ │  选中：SUN 填充、上抬 2 px
│ └──────────────────────────┘ │
│                              │
│  长按 OK 录音 · 长按 ↓ 设置   │  提示，中文 16，MUTED
└──────────────────────────────┘
```

一个日期头加底栏之间能放五行。整页滚动时选中项落到新的首行；列表从不脱离选中独立滚动，
所以高亮卡片永远在可视区内。

### 详情

```text
┌──────────────────────────────┐
│ ‹ 08:32 · 1:24         82%   │  页头，36 px
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 下午三点和张工对了下进度  │ │  正文面板，圆角 14
│ │ 他说下周三之前把测试环境  │ │  中文 20 常规，行高 28
│ │ 搭好……                   │ │  折叠：六行
│ │                          │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ ▶   00:12 / 01:24  ▬▬──  │ │  播放条，胶囊，高 48
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

折叠显示六行；展开后面板撑满可用空间并可滚动。播放条是胶囊而不是卡片——这是唯一一处刻意
的形状例外，让人不用读字就知道"这是会出声的那个东西"。

### 录音

```text
┌──────────────────────────────┐
│ ● 录音               82%     │  红点 0.8 Hz 呼吸
├──────────────────────────────┤
│        01:23                 │  Montserrat 28，INK
│   ▮▮▮▮▮▮▮▮▯▯▯▯               │  电平条，十二根
│                              │
│   OK 停止 · 长按 OK 取消      │  中文 16，MUTED
└──────────────────────────────┘
```

这里的卡片就是整块内容区，所以投影读起来像"整页本身是一张贴纸"。计时到 04:30 变 `CORAL`。

### 设置

```text
┌──────────────────────────────┐
│ 设置                   82%   │
├──────────────────────────────┤
│ 网络      已连接 MyHome    › │
│ 服务器    NAS-01 · 可达    › │
│ 音量      80%              › │
│ 自动息屏  30 秒            › │
│ 深度休眠  5 分钟           › │
│ 自动播放  关                 │
└──────────────────────────────┘
```

行高 40、间距 6；七行放不下，所以和备忘录列表一样"选择带着列表滚"。数值列右对齐且用
`MUTED`，标签用 `INK`。

子页把行列表换成一张居中的卡片：选项胶囊纵向排列，当前项填充 `SUN`。OK 保存、长按取消，
与产品文档一致。

## 6. 动效

便宜、有目的、且绝不在放音期间运行。

| 时机 | 动效 | 代价 |
| --- | --- | --- |
| 选中移动 | 卡片上移 2 px，60 ms | 一个属性动画 |
| 录音红点 | 透明度 1.0 → 0.35 → 1.0，800 ms 循环 | 一个属性动画 |
| 面板展开/收起 | 高度 150 ms，ease-out | 一次布局重算 |
| 换页 | 直接切换 | 无 |

全局不做缩放与旋转：在这颗芯片上两者都会触发子树的全软件重绘，"贴纸歪一点"的效果不值得
那点帧预算。真要歪，必须作为预渲染图片带进来，不能用实时变换。

## 7. 渲染约束

- **不要模糊阴影**。按第 4 节用第二张圆角矩形实现。
- **不要旋转、不要缩放**。理由同上。
- **图标不用图片**，只用 LVGL 符号字形。
- **卡片不叠卡片**。需要分组时在卡片内部用分隔线。
- **重绘范围受控**。绘制缓冲是 240 × 20，列表滚动只重画受影响的行。
- **底色一律平涂**。不用渐变、不用网纹；它们既费算力，经 RGB565 量化后还会把配色搅浑。

## 8. 该做与不该做

| 该做 | 不该做 |
| --- | --- |
| 每张卡片都在 8 px 安全区内 | 让卡片压到 30 px 圆角弧线上 |
| 全页统一 2 px 描边 | 同一页混用 1 px 和 3 px |
| 每个状态只用一个主色 | 为了"活泼"给四张卡片各上一种颜色 |
| 允许投影轻微压到下一张卡 | 把投影做模糊 |
| 标签用 16 px 粗体、正文用 20 px 常规 | 把长段正文排成粗体 |

## 9. 验收

1. 30 px 遮罩之外的像素只有纯黑。
2. 每张卡片距屏幕边缘至少 8 px。
3. 选中卡片靠填充、上抬、投影三者就能在半米外辨认。
4. 状态点不依赖颜色也能区分。
5. 20 px 正文没有下缘被切、也没有行与行粘连。
6. 录音或播放期间没有任何动效在跑。
7. 换页重绘时没有可见的闪白。
