# 语音日记 — 产品方案

实现快照：2026-11-09，以当前 `feature/voice-memo` 代码为准。本文描述现有行为；
交付状态、待完善工作和验收统一在[里程碑](../project/milestones.zh_CN.md)中跟踪。

## 1. 定位

把 FoloToy AI Passport 变成随身语音日记本：记录念头，交给服务器转写，阅读文字，
回听原声。产品用来捕捉精炼的灵感，保持有选择地按住录音、松手结束的短记方式。记录没有标题、标签、文件夹或待办状态；设备上不提供服务器历史的编辑和删除入口。

## 2. 部署形态

设备连接同一局域网内的服务器。服务器保存历史并调用云端转写服务，也支持用于本地开发的
假转写器。设备本身不做语音识别。

## 3. 导航

```text
列表 --OK 单击--> 详情 --OK 长按--> 列表
  |
  +--按住 OK 1 秒--> 录音 --松手 / 五分钟上限--> 保存 / 取消
  |
  +--长按 UP 或 DOWN--> 设置 --长按 UP 或 DOWN--> 列表
```

## 4. 界面与操作

### 4.1 列表

首页用四条双行终端记录作为移动窗口。本地待上传、被拒及旧版遗留待处理录音在前，之后是一页最多
24 条服务器记录；选中项始终可见。服务器记录按最新在前排列，越过页面边界时请求相邻服务器页，
失败保留当前页。没有按天分组标题。

| 按键 | 当前行为 |
| --- | --- |
| UP / DOWN 单击 | 移动选中项；页边界有游标时读取较新/较旧历史 |
| OK 单击 | 页面加载完成后打开选中记录 |
| 按住 OK | 短按保持列表，180 ms 后显示独立准备圆环；按住至少一秒且资源就绪后开始录音 |
| 长按 UP 或 DOWN | 进入设置 |

180 ms 内松手仍是普通短按，可打开选中记录。进入准备阶段后，松手只取消，吞掉同一次
手势后续的单击，不打开详情或确认录音；下一次独立按下 OK 恢复正常单击。任何本地未处理录音都阻止新录音，
并以待上传/被拒状态保持可见。

明确的 OK 长按可以贯穿息屏唤醒，进入原有一秒录音准备；短按唤醒只亮屏。深睡启动后，
仍按住 OK 时会在应用就绪后开始准备，提前松手取消；UP/DOWN 唤醒手势仍被吞掉。
实际启动到采音延迟需要实机测量。

底部显示当前页选中序号/条数、读取/错误或空状态。所有页面显示电量百分比，读不到时显示 `--`。
未对时时间显示 `--:--`，时长仍显示；摘要独占一行，时间和时长放在独立元信息行。服务器无摘要时区分等待、转写中、失败和就绪无文本。

### 4.2 详情与播放

详情进入后直接显示完整正文面板，异步请求文字，只保留一个 2 KiB 窗口，输入不等待服务器。
本地条目提示待上传/被拒且可回听；远程空文本、等待、失败、不存在和离线使用各自说明，
不会声称远程原始录音存于设备。

| 按键 | 当前行为 |
| --- | --- |
| OK 单击（自动播放关闭或播放结束） | 播放原始录音 |
| 播放中 OK 单击 | 在当前进度暂停 |
| 暂停状态 OK 单击 | 从暂停位置继续同一音源 |
| OK 长按 | 停止播放、取消文字读取并返回列表 |
| 详情、播放或暂停时 UP / DOWN 单击 | 音量增加/减少 20%，限制在 0–100%；应用并保存 |
| 详情、播放或暂停时 UP / DOWN 长按 | 切换上一条/下一条录音，支持跨服务器页，首尾不循环 |

窗口在 UTF-8 边界结束；阅读期间文本被编辑时，从新版本开头重新读取，不拼接不同版本。
加载/失败期间保留已读文字。不支持的字符显示 `?`，服务器原文不变。

切换前先停止并等待旧音频释放，翻页期间保持当前详情，翻页失败保留原录音。
读取期间开始的确认手势不会误播放刚加载的新条目。

正文按音频播放进度和转写字节长度的比例自动滚动；暂停时停止滚动，重播时回到开头，
相邻 2 KiB 正文窗口自动加载。当前没有逐字或逐句时间戳，因此是近似跟随。
紧凑终端状态行用中文显示传输/正文状态及“音量”百分比，本地等待上传标识缩为“待传”。
音量保存失败保留已确认值并提示错误；正文读取失败按间隔重试。

本地待上传、被拒及旧遗留记录从设备文件播放；播放持有文件时上传不能移除音源，在途上传成功
也等待播放确认退出后再删除。上传释放临时文件后，详情改为远程读取/播放同一 ID。
服务器音频直接流播，不建本地缓存。自动播放在进入时启动，默认关闭；自然结束回完整详情状态。

### 4.3 录音

录音全程按住 OK。独立准备页只显示圆环、OK 与准备状态。持续转动的圆环覆盖后台退出、
编码器/缓冲/文件准备，以及超过一秒最短按住时间的等待。确认同一次按住仍有效且资源就绪前，
录音任务等待启动信号，不采集、不开始计时。松手释放已准备的资源；排队的松手/重按回调不能误启动旧手势。
开始采音后切换到大字计时、
二十个真实输入电平采样的滚动历史、输入百分比和录音标记；这是振幅历史，不是 PCM 波形。
松开 OK 停止；4:30 计时反白，5:00 自动请求停止。显示计时和上限使用单调墙钟，每 200 ms 检查；存储音频时长按编码采样数计算。
准备、录音、保存、捕捉灵感和输入电平说明统一为中文，与其它页面一致；录音灯仅在采集中显示。数字 PCM 连续三秒 RMS 低于 80 时提示
声音偏小；至少 1% 采样接近满量程并持续 180 ms 时提示声音过大。这些只是视觉提示，
不是经声学校准的电平或自动增益，信号恢复正常即解除。暂存区已满时阻止新录音并提示空间不足；
读写失败保留可恢复数据。不使用声音提示，避免混入录音。

### 4.4 保存/取消确认

停止时先完成本地文件，隐藏实时输入和电平历史，在最终时长下显示保存/取消选择条，默认选保存。UP 或 DOWN 切换，
OK 确认，长按 OK 取消。五分钟上限也进入同一选择条，不会自动确认保存。

“自动保存”为可选设置，默认关闭。开启后，新录音正常结束即回列表，提供三秒 OK 撤销窗口。
窗口从首次成功取得渲染锁后开始计时；期间文件已关闭并保留为草稿，不允许上传或休眠。
OK 只删除该草稿；到期通过原有保存操作使其允许上传。保存/删除失败回到手动确认。
中断或恢复的草稿始终由用户手动选择，不受自动保存设置影响，不增加副本或队列。

保存才使本地草稿允许上传并返回列表，取消只删除草稿。文件操作失败会保留选择并提示错误。
录音中和未确认草稿在重启后仍阻止上传。中断后已存储的完整帧恢复为保存/取消选择，
无效或空数据隔离保留，等待用户处理；尚未写入的音频无法恢复。
上传成功删除本地文件，所有未处理录音都继续占用唯一处理槽。

HTTP 4xx 被拒后**总共尝试三次，包含第一次请求**。第三次仍被拒后停止自动上传，
在列表页弹出带录音时间和时长的重试/删除选择；其它页面先继续当前操作，返回列表后再提示。
UP/DOWN 切换，OK 确认；默认重试，长按 OK 也重试。
重试使用同一个录音 ID 重新开始一轮，最多三次被拒尝试。
只有明确选择删除才移除被拒录音；文件操作失败时文件和弹窗仍在，可重新选择。

本地存储只是一条录音的处理槽，不是存档。上传成功或明确删除之前始终禁止新录音，
包括选择重试后及重启后。未处理的被拒文件离线时也会再次询问。
新固件不生成新的保留存档；前一版留下的 `.keep` 兼容为未完成录音，仍占用处理槽并提供
重试/删除。如果已经有多条旧文件，先保留并逐条处理完，再允许录制新的一条。

### 4.5 设置

UP/DOWN 在涵盖全部八项的五行窗口内移动，长按任一方向键返回列表。

| 行 | 显示 | OK 单击 |
| --- | --- | --- |
| 网络 | SSID、连接中、未配置或未连接 | 进入蓝牙配网 |
| 服务器 | 已发现的 `host:port`、查找中、等待网络或未发现 | 排队重新发现并验证 API |
| 音量 | 0 / 20 / 40 / 60 / 80 / 100%，默认 80% | 打开调值浮层 |
| 自动息屏 | 常亮 / 30 秒 / 1 分钟 / 3 分钟，默认 30 秒 | 打开调值浮层 |
| 深度休眠 | 不自动 / 1 分钟 / 5 分钟 / 15 分钟，默认 5 分钟 | 打开调值浮层 |
| 自动播放 | 开 / 关，默认关 | 立即切换 |
| 自动保存 | 开 / 关，默认关 | 设置提交成功后切换 |
| 关于 | `v0.1` | 无动作 |

调值浮层内 UP/DOWN 只修改草稿，不写存储或应用音量。OK 保存当前项，长按取消并恢复已存值显示。
写入/提交失败保留浮层与草稿，提示处理失败，允许重试或取消。自动播放只有保存成功才立即切换，
失败保留原来的已确认值。音量编辑统一上增下减，0/100% 处停住，进度条平滑变化且重复刷新不重启动画。
音量保存成功后生效，没有试听音。编辑期间阻止空闲休眠。
先按息屏设置关闭背光，再从实际熄屏时刻开始休眠倒计时。默认先等 30 秒息屏，再等 5 分钟深睡；
常亮时不自动深睡。唤醒或恢复亮屏会重置熄屏后的计时，延迟轮询不会跳过这一等待期。息屏后的短手势只唤亮屏幕，明确的 OK 长按继续进入录音准备。
录音/选择确认、播放（含暂停）、配网及按键按住保持亮屏；已关闭的待传录音允许休眠；活动录音、未确认草稿、恢复错误和撤销窗口仍阻止休眠。
必须先等待联网任务停止确认，再检查文件；持有写入所有权期间，第二次安全复查复用此前的文件扫描。
不配置周期唤醒，手动唤醒后恢复正常联网流程继续同步。深睡唤醒回到列表，仍按住 OK 时在启动就绪后进入准备，其它唤醒手势仍被吞掉。

### 4.6 蓝牙配网

从网络行进入，BLUFI 广播名为 `BLUFI_MEMO`。配套微信小程序名称见
[配网指南](../development/engineering/wifi-provisioning.zh_CN.md#小程序名称)。
手机提交 2.4 GHz 网络的 SSID 和密码，没有服务器地址或令牌字段。进入前应用请求停止
正常联网工作任务。

页面显示蓝牙/Wi-Fi 状态。长按 UP/DOWN 取消、清理并返回设置。获得 IP 后留两秒报告时间，
随后恢复正常联网。模块/启动致命失败走同一清理路径；清理失败保留资源，完成后才恢复
正常 Wi-Fi。Wi-Fi 连接失败向手机报告并回到等待；底部显示配网说明，不常驻按键操作说明。

## 5. 存储与联网行为

- 1 MiB 本地分区用于暂存录音。文件由 80 字节头部和 Opus 帧构成；停止录音时回填时长和帧数。
- 启动时将中断文件的完整包恢复为未确认草稿，截去不完整尾包；无效或空文件隔离保留，
  不自动删除。尚未写出的 RAM 音频会丢失。
- 挂载失败保留已有 Flash，只有确认整块录音分区均为擦除值才自动初始化；NVS 失败不擦除
  已存设置或 Wi-Fi 凭据。
- 有已存 Wi-Fi 凭据时自动连接并启动对时。服务器地址无需输入，也没有编译期写死，
  通过同一局域网的 mDNS 发现。
- 上传成功删除本地文件。HTTP 4xx（含 429）累计三次后留下可见的 `.bad` 文件，等待重试/删除。
  重试把同一文件恢复为 `.memo` 并重置三次预算，不会释放处理槽；只有上传成功或明确删除才释放。
  传输、发现和 5xx 失败保留待上传文件继续重试，不占用被拒次数预算。
- 被拒计数保存在当前轮次/启动的 RAM 中；`.bad` 及旧版 `.keep` 跨重启存在，重新提供重试/删除，
  不会自动删除。
- 服务器元数据缓存在 RAM，刷新失败会保留旧缓存，所以断网时可能仍看到先前的行，
  但其正文和音频仍依赖服务器。服务器历史没有持久化离线归档。
- SSE 通知请求新的权威列表，包含重连、编辑和删除，轮询作为补充。固件跟随双向历史游标，
  始终只保留一页。

## 6. 视觉呈现

界面是单色磷光绿 CRT 终端：黑底、方角面板与 1 px 线、无投影；选中项为反白。
生成的 16 px、20 px 中文字体子集回退到 Montserrat。静态文字检查两套字体，动态不支持字符
显示 `?`。录音选择和主要操作使用中文，保留实体 OK 标识与技术名称。
已实现的尺寸和素材见[视觉设计语言](../design/visual-language.zh_CN.md)。


列表、详情、设置、准备/采音和被拒弹窗移除常驻底部按键说明，原有手势继续生效。实时状态、
保存/删除选择、条数、自动保存倒计时和必要错误反馈继续显示。正常采音不显示松手说明，
声音偏小/过大仍显示反馈。详情页将腾出的区域用于正文，临时反馈复用状态行。
