# 语音日记 — 产品方案

实现快照：2026-10-27，以当前 `feature/voice-memo` 代码为准。本文描述现有行为；
交付状态、待完善工作和验收统一在[里程碑](../project/milestones.zh_CN.md)中跟踪。

## 1. 定位

把 FoloToy AI Passport 变成随身语音日记本：记录念头，交给服务器转写，阅读文字，
回听原声。记录没有标题、标签、文件夹或待办状态；设备上不提供服务器历史的编辑和删除入口。

## 2. 部署形态

设备连接同一局域网内的服务器。服务器保存历史并调用云端转写服务，也支持用于本地开发的
假转写器。设备本身不做语音识别。

## 3. 导航

```text
列表 --OK 单击--> 详情 --OK 长按--> 列表
  |
  +--按住 OK 1 秒--> 录音 --松手 / 五分钟上限--> 保存 / 取消
  |
  +--长按 UP 或 DOWN--> 设置 --长按 UP 或 DOWN--> 列表
```

## 4. 界面与操作

### 4.1 列表

首页绘制五张固定卡片，包含时间、文字和时长。本地待上传、被拒及旧版遗留待处理录音在前，之后是最多 24 条
服务器记录。服务器记录按时间倒序；没有按天分组标题。选中项可以移到五张卡片之外，
但显示窗口始终停在前五条。

| 按键 | 当前行为 |
| --- | --- |
| UP / DOWN 单击 | 移动选中项，到头停止 |
| OK 单击 | 打开选中记录 |
| 按住 OK | 立即显示圆环，一秒填满后开始录音 |
| 长按 UP 或 DOWN | 进入设置 |

圆环未满时松开会取消录音准备；短按随后可打开选中记录。如果上一条录音仍待上传或等待被拒处理选择，
新录音会被阻止，并显示简短提示。

底部显示条数或空状态。电量百分比显示在本页；读不到时显示 `--`。未对时的时间显示
`--:--`。

服务器记录有转写摘要时显示摘要；`ready` 但文字为空时显示无转写，其余状态显示转写中。
因此转写失败的记录当前也会显示转写中。

### 4.2 详情与播放

打开记录直接进入展开的正文面板和播放条。服务器转写在进入时读取，目标缓冲为 512 字节。
没有文字或获取失败时显示固定说明，内容是录音保存在本地、联网后可看转写；服务器记录
无文字时也使用同一说明。

| 按键 | 当前行为 |
| --- | --- |
| 第一次 OK 单击 | 播放原始录音 |
| 播放中 OK 单击 | 停止播放，进入暂停状态 |
| 暂停状态 OK 单击 | 从头重新播放 |
| OK 长按 | 停止播放并返回列表 |
| UP / DOWN 单击 | 当前应用没有可见的正文滚动 |

本地待上传、被拒及旧版遗留待处理记录从设备文件播放；服务器记录直接流式播放，不在本地缓存音频。
自动播放会在打开详情时启动，默认关闭。自然播放结束后回到展开详情状态。

### 4.3 录音

录音全程按住 OK。页面显示大字计时、十二根电平条和录音标记。松开 OK 停止；
4:30 计时变红，5:00 自动请求停止。显示计时和上限使用单调墙钟，每 200 ms 检查；存储音频时长按编码采样数计算。

### 4.4 保存/取消确认

停止时先完成本地文件，再显示保存/取消选择条，默认选保存。UP 或 DOWN 切换，
OK 确认，长按 OK 取消。五分钟上限也进入同一选择条，不会自动确认保存。

保存才使本地草稿允许上传并返回列表，取消只删除草稿。文件操作失败会保留选择并提示错误。
录音中和未确认草稿在重启后仍阻止上传。中断后已存储的完整帧恢复为保存/取消选择，
无效或空数据隔离保留，等待用户处理；尚未写入的音频无法恢复。
上传成功删除本地文件，所有未处理录音都继续占用唯一处理槽。

HTTP 4xx 被拒后**总共尝试三次，包含第一次请求**。第三次仍被拒后停止自动上传，
在列表页弹出带录音时间和时长的重试/删除选择；其它页面先继续当前操作，返回列表后再提示。
UP/DOWN 切换，OK 确认；默认重试，长按 OK 也重试。
重试使用同一个录音 ID 重新开始一轮，最多三次被拒尝试。
只有明确选择删除才移除被拒录音；文件操作失败时文件和弹窗仍在，可重新选择。

本地存储只是一条录音的处理槽，不是存档。上传成功或明确删除之前始终禁止新录音，
包括选择重试后及重启后。未处理的被拒文件离线时也会再次询问。
新固件不生成新的保留存档；前一版留下的 `.keep` 兼容为未完成录音，仍占用处理槽并提供
重试/删除。如果已经有多条旧文件，先保留并逐条处理完，再允许录制新的一条。

### 4.5 设置

UP/DOWN 在七行之间移动，长按任一方向键返回列表。

| 行 | 显示 | OK 单击 |
| --- | --- | --- |
| 网络 | SSID、连接中、未配置或未连接 | 进入蓝牙配网 |
| 服务器 | 已发现的 `host:port`、查找中或未发现 | 无动作 |
| 音量 | 0 / 20 / 40 / 60 / 80 / 100%，默认 80% | 打开调值浮层 |
| 自动息屏 | 常亮 / 30 秒 / 1 分钟 / 3 分钟，默认 30 秒 | 打开调值浮层 |
| 深度休眠 | 不自动 / 1 分钟 / 5 分钟 / 15 分钟，默认 5 分钟 | 打开调值浮层 |
| 自动播放 | 开 / 关，默认关 | 立即切换 |
| 关于 | `v0.1` | 无动作 |

调值浮层内 UP/DOWN 循环选项，每次调整立即生效并写入存储，持久化错误不在界面显示。OK 单击和长按都关闭浮层，
不会回滚数值，尽管当前提示仍写保存/取消。调音量会直接影响播放，没有试听提示音。
息屏和休眠时间只是保存的设置值，当前不会触发背光变化或自动休眠。

### 4.6 蓝牙配网

从网络行进入，BLUFI 广播名为 `BLUFI_MEMO`。配套微信小程序名称见
[配网指南](../development/engineering/wifi-provisioning.zh_CN.md#小程序名称)。
手机提交 2.4 GHz 网络的 SSID 和密码，没有服务器地址或令牌字段。进入前应用请求停止
正常联网工作任务。

页面显示蓝牙和 Wi-Fi 状态，成功时显示 SSID 与 IP，当前会停留在结果页。
底部提示长按 OK 退出，但该手势没有效果；长按 UP/DOWN 只改变内部状态，没有执行页面
清理或可见地返回设置。Wi-Fi 连接失败会向手机报告失败，并回到连接或等待状态；
设备端没有密码错误、网络不存在等具体原因文案。

## 5. 存储与联网行为

- 1 MiB 本地分区用于暂存录音。文件由 80 字节头部和 Opus 帧构成；停止录音时回填时长和帧数。
- 启动时将中断文件的完整包恢复为未确认草稿，截去不完整尾包；无效或空文件隔离保留，
  不自动删除。尚未写出的 RAM 音频会丢失。
- 有已存 Wi-Fi 凭据时自动连接并启动对时。服务器地址无需输入，也没有编译期写死，
  通过同一局域网的 mDNS 发现。
- 上传成功删除本地文件。HTTP 4xx（含 429）累计三次后留下可见的 `.bad` 文件，等待重试/删除。
  重试把同一文件恢复为 `.memo` 并重置三次预算，不会释放处理槽；只有上传成功或明确删除才释放。
  传输、发现和 5xx 失败保留待上传文件继续重试，不占用被拒次数预算。
- 被拒计数保存在当前轮次/启动的 RAM 中；`.bad` 及旧版 `.keep` 跨重启存在，重新提供重试/删除，
  不会自动删除。
- 服务器元数据缓存在 RAM，刷新失败会保留旧缓存，所以断网时可能仍看到先前的行，
  但其正文和音频仍依赖服务器。服务器历史没有持久化离线归档。
- SSE 通知更新缓存元数据，轮询作为补充。固件浏览不会跟随服务器分页游标。

## 6. 视觉呈现

界面使用暖纸色背景、白色卡片、深色边框和实心偏移投影；选中项变为黄色并略微上移。
生成的 16 px、20 px 中文字体子集回退到 Montserrat。录音操作及部分提示使用英文。
已实现的尺寸和素材见[视觉设计语言](../design/visual-language.zh_CN.md)。
