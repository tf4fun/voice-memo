# 语音日记 — 产品方案

状态：草案，2026-10-26 与产品负责人确认。字号、列表密度、提示语措辞等实现细节
刻意留白，开发期按真机效果决定。

## 1. 定位

语音日记：把 FoloToy AI Passport 变成一台**随身语音日记本**。几秒钟说下一个念头，
回头能当文字读。

它只负责记录与回顾，不负责管理。没有待办状态、没有勾选框、没有"完成"、没有收件箱。
一条记录就是某个时刻的声音，加上它转出来的文字。

## 2. 核心场景

| 场景 | 用户做什么 | 产品必须保证 |
| --- | --- | --- |
| 灵感速记 | 走路时按住 OK 三秒，说二十秒，松手 | 立刻存住，之后自己上传，绝不丢 |
| 睡前回顾 | 往回翻今天和昨天，打开一条，读文字 | 240×320 屏幕读得下去，最新的在最前 |
| 长时间记录 | 录一段五分钟的会议复盘 | 时长看得见，有上限防止失控 |
| 再听一遍 | 打开一条，播放原始录音 | 放的是原声，不是重新合成的 |
| 首次配置 | 用手机配好 WiFi，确认服务端已找到 | 设备上不需要键盘 |

## 3. 产品形态

一台设备 + 一个云端服务。设备只做四件事：录、翻、读、听。所有文字处理都在服务器，
所以设备永远不必等转写。

三个界面，外加一个设置区：

```text
列表(首页) --OK单击--> 详情(文字/播放) --OK长按--> 返回列表
    |
    |--长按OK 3秒--> 录音 --OK单击--> 保存并回列表
    |
    +--长按UP 或 长按DOWN--> 设置 --OK单击--> 该项的子页
```

## 4. 界面与操作

### 4.1 列表（首页）

按时间倒序，按天分组（今天 / 昨天 / 具体日期）。还没同步到服务器的条目照常排在
时间轴里，带一个小状态圆点。

| 按键 | 行为 |
| --- | --- |
| UP / DOWN | 上下移动选中项 |
| OK 单击 | 打开该条 |
| OK 长按 3 秒 | 开始录音 |
| UP 长按 或 DOWN 长按 | 进入设置 |

列表底部常驻一行提示，说明怎么录音、怎么进设置。正文超长在字符边界截断，绝不切坏
多字节字符。

设备还没配网时，列表显示一行空状态提示，指向设置页，而不是一片空白。

### 4.2 详情

上面是文字，下面是播放条。OK 单击按三步循环，不做焦点切换：

```text
折叠 --OK--> 展开 --OK--> 播放 --OK--> 暂停 --OK--> 播放 …
     |
     +------------ OK 长按：返回列表 ------------+
```

| 状态 | OK 单击 | UP / DOWN | OK 长按 |
| --- | --- | --- | --- |
| 折叠（六行，末尾省略号） | 展开全文 | 上一条 / 下一条 | 返回列表 |
| 展开 | 开始播放 | 滚动文字 | 返回列表 |
| 播放中或暂停 | 暂停或继续 | 滚动文字 | 返回列表 |

"展开"对本次访问是单向的：返回列表再进来，恢复折叠。

打开**自动播放**时（见 4.5），进入详情页立即开始播放，此时 OK 的第一下是暂停，
而不是展开。

### 4.3 录音

大字计时、电平条，右上角电量。**按住即录、松手即停**，整个录音只有一个长按动作：

```text
按下 OK ──圆环填充(1 秒)──► 开始录音（手指仍按着，直接说）
                              │
                          松开 OK
                              ▼
                    结束并弹出：保存 / 取消
```

| 阶段 | 按键 | 行为 |
| --- | --- | --- |
| 圆环填充中 | 提前松开 | 放弃，不产生录音 |
| 录音中 | 松开 OK | 结束录音，弹出选择条 |
| 选择条 | UP / DOWN | 在「保存」与「取消」之间切换 |
| 选择条 | OK 单击 | 确认当前项 |
| 选择条 | OK 长按 | 等同取消 |

圆环从**按下瞬间**开始计算，不叠加长按判定时间，所以从触碰到开始录音大约一秒。
录音期间不接受其它导航，避免误触把一句话掐断。

### 4.4 进入录音的动作

在列表上**按下** OK，屏幕立刻出现一个一秒填满的圆环；填满即开始录音，此时手指仍在键上。
提前松手即取消。圆环是"还要按多久"的唯一反馈，也是"打开这一条"和"开始录音"之间的分界。

### 4.5 设置

上、下两个方向的长按都进设置，这样无论用户正看着列表哪一端，手势都一致。

| 行 | 显示 | OK 单击 |
| --- | --- | --- |
| 网络 | `已连接 <SSID>` 或 `未连接` | 进入蓝牙配网（4.6） |
| 服务器 | `已发现 <名称> · 可达` 或 `未发现` | 重新发现（4.7） |
| 音量 | `40 / 60 / 80 / 100%` | 进入音量子页 |
| 自动息屏 | `常亮 / 30 秒 / 1 分钟 / 3 分钟` | 进入息屏子页 |
| 深度休眠 | `不自动 / 1 分钟 / 5 分钟 / 15 分钟` | 进入休眠子页 |
| 自动播放 | `开 / 关` | 就地切换 |
| 关于 | 固件版本、设备短 ID、待上传条数 | 无动作 |

设置列表里 UP/DOWN 只移动选中项；进入子页后统一规则：**OK 单击保存并返回，
OK 长按取消并返回**。

- **音量**是单行大数字加调整提示。每按一下立刻用新音量播一声短提示音，靠听决定，
  不靠猜。
- **自动息屏与深度休眠**是选项列表：UP/DOWN 选，OK 保存。默认分别是 30 秒和 5 分钟。
- **自动播放**默认关：在公共场合翻日记，不该突然出声。
- **关于**只读。

### 4.6 蓝牙配网

从"网络"行进入。设备停止正常联网用途，改为蓝牙广播；手机通过配套微信小程序
（名称见[上游配网文档](../development/engineering/wifi-provisioning.zh_CN.md#小程序名称)）
提交 2.4 GHz 网络的名称和密码。

```text
┌──────────────────────────┐
│ 蓝牙配网                  │
├──────────────────────────┤
│ 小程序里选择：            │
│     BLUFI_MEMO            │
│                          │
│ ○ 等待手机连接…           │
│                          │
│ 长按 OK 取消              │
└──────────────────────────┘
```

广播名必须以 `BLUFI` 开头——小程序只列出这类设备。屏幕上显示的就是这个精确名字，
方便用户对上号。

状态依次显示：等待手机连接、接收网络信息、连接中、成功，或失败原因（密码错误、
找不到该网络）。成功后自动回到设置页，"网络"行更新。

**这条通道只承载网络名称和密码**，传不了服务器地址、令牌或任何其它自由文本，
产品不假装能传。

### 4.7 服务器发现

服务器地址既不在设备上输入，也不在编译期写死。设备自己在同一局域网内找到它。

- "服务器"行只读：显示发现的名称，以及服务器是否应答。
- 没找到时显示 `未发现`，OK 单击即重新搜索。
- 找不到不算错误状态：设备照常录音、照常排队，自己重试。

## 5. 行为规则

1. **先存住，再上传。** 录完先落在设备上，再传服务器；断网不牺牲任何一条记录。
2. **没转写完不算异常。** 转写在后台进行。还没有文字的条目照样能打开、能播放，并如实显示。
3. **状态要安静。** 待上传、待转写只是一个圆点，详情页最多一行短提示——不是任务状态。
4. **五分钟上限。** 4:30 计时变红；5:00 自动结束并弹出保存/取消，不让一次按压无限延长。
5. **一条记录就是一个时刻。** 没有标题、标签、文件夹，设备上也不能编辑。
6. **电量常驻。** 电量读不到时画图标不画数字，不显示假数值。
7. **做事时不睡。** 录音、播放、蓝牙配网期间不熄屏、不休眠。
8. **屏幕可以灭，上传不能断。** 有未发送条目时允许熄屏，但队列排空前不深度休眠。
9. **醒来回到列表。** 休眠唤醒一律回到列表页，绝不回到录音页。

## 6. 明确不做

- 待办、勾选、完成度、提醒
- 在设备上编辑、改标题、打标签、删除
- 在设备上输入 WiFi 密码或服务器地址
- 编译期写死服务器地址
- 在设备上做恢复出厂设置
- 搜索、收藏、导出
- 多用户、共享日记
- 离线翻阅服务器历史（断网时只有尚未上传的条目可见）

## 7. 用户视角的验收

1. 在列表上按住 OK 三秒开始录音；提前松手取消。
2. 长按 UP 或长按 DOWN 都能进设置。
3. 设置子页里 OK 保存并返回，长按 OK 取消并返回。
4. 调音量时当场就能听到变化，不用退出子页再试。
5. 自动息屏与深度休眠按设定生效；录音或播放期间都不触发。
6. 用指定小程序能完成蓝牙配网；密码错误时给出原因，而不是无声失败。
7. "服务器"行不需要任何输入就能显示发现结果，重新发现后能恢复。
8. 录完的条目立刻出现在列表顶部，此时还没上传、也没转写。
9. 连续按 OK，能在"折叠 → 展开 → 播放 → 暂停"之间循环，不需要别的键。
10. 在详情页任何状态下长按 OK 都能回到列表。
11. 录满五分钟自动停止并保存。

## 8. 刻意未定

列表密度（紧凑时间轴还是两行卡片）、字号、提示语措辞属于实现细节。会对着真机决定，
并按反馈调整，但不改变上面这套模型。
